# 互換性と検証メモ

2026-10-22時点．macOSのSafari＋Userscriptsで基本動作を確認しています．iOS・iPadOSの実機と，ログイン後の各機能の網羅的な確認は未実施です．

自動テストはNode.jsのVM・DOM代替オブジェクトで行っています．Safariでの実機試験とは異なります．

| 確認項目 | 維持した方式・確認結果 | 実機で確認が必要な点 |
| --- | --- | --- |
| 実行タイミング | `@run-at document-start` を維持．全体背景とホームのレイアウトのCSSを先に追加し，主処理は `DOMContentLoaded` 後に必要な要素が揃い次第開始．画像などの `load` と固定500msの待機を削除．注入時にDOMができている場合も一度だけ開始． | Userscriptsの注入時期，実サイトでの描画・画面遷移，遅れて初期化されるページ側の機能． |
| ページ側のjQuery | `@inject-into page`・`@grant none` を維持。既存の `window.jQuery.fn.submit` とネイティブの `submit` を一時的に捕捉して添付を取得。捕捉と復元を代替オブジェクトで確認。外部jQueryは追加しない。 | 実サイトのjQuery・送信関数との連携、CSPによる注入制限。 |
| フォーム送信 | 成績・時間割取得は既存のFormData／URLSearchParamsと同一オリジンの認証情報を使用。CSRFフィールドの引き継ぎをテスト。添付プレビューのGETだけ本文をクエリへ修正し、POSTのFormDataは維持。 | 実際の認証・トークン・ダウンロード処理、単位情報への遷移、提出取消後の復帰、SSO自動同意。 |
| Cookie・ストレージ | Cookieの日本語データの往復と削除、初期化時のsessionStorageの扱いをテスト。保存方式・キーは維持。 | Safariの保存制限・データ削除・プライベートブラウズ、画像の保存と復元。 |
| 添付プレビュー | PDF・テキストはBlob URLをiframeへ、画像はimgへ表示。GET／POST、HTTPエラー表示、MIME選択、画像用URLの解放をテスト。 | iPhone・iPadでのPDFのページ送り・スクロール、文字コード、画像形式、ログイン切れ時の応答。 |

添付のGETフォームに本文を指定するとFetchの仕様上エラーになるため、クエリで送るようにしています。また、HTTP 4xx・5xxをファイル扱いしないようにしています（[Fetch Standard](https://fetch.spec.whatwg.org/#dom-request)）。v1.12.0では，背景画像の設定を3種類に分け，警告を始める日数を追加しています．画像は半透明の上部メニューの背後までウインドウ全体に表示し，CSSの `cover` でサイズ変更に追従します．ホーム以外では通常時の画像を使います．SSO・ログイン画面・iframe内には背景を追加しません．

v1.12.3では，切り取り画面を外し，画像全体を最大2048px四方に収まるように縮小して保存します．表示はCSSの `cover` でウインドウに追従します．縦横比が違うときは中央を基準に端が画面の外へ出ますが，保存した画像は切り抜きません．過去に切り抜いて保存した画像は，元画像を選び直す必要があります．macOS Safariでは，PNGをファイル選択画面から選び，切り取り画面なしで反映・再読み込み後も元の320×200pxを保って保存できることを確認しました．検証後は元の画像設定へ戻しています．メニュー展開時の `.c-wrapper` の `filter: blur(2px)` によって背景の高さがページ全体へ変わることを修正前に再現し，修正後はメニュー開閉にかかわらず表示領域と一致することを確認しました．画面幅を1424pxから376pxに変えた場合も背景が表示領域に追従します．

### 保存内容と制約

- Cookie（学情サイト内、`path=/`）: `cg_hidden_*` は非表示課題のタイトル・科目・提出期間・状態など、`cg_grade_save_enabled` は通知設定、`cg_grade` は比較用ハッシュ、`cg_grade_updated` は更新フラグです。保存期限の指定は365日ですが、Safariのポリシーやサイトデータ削除で早く消えることがあります。
- localStorage: `cg-header-image` に通常時，`cg-header-image-warning` にn日未満，`cg-header-image-critical` に1日未満の背景画像，`cg-header-warning-days` にn日を保存します．既存の `cg-header-image` はそのまま使います．容量不足で保存できない場合は設定画面にエラーを表示し，前の画像を残します．
- sessionStorage: `cg-home-deadlines` に同じタブで前回確認した未提出課題の締め切り日時だけを保存し，ホームの初期背景に使います．最新の一覧を取得したら更新します．`cg_return_to_task` に提出取消後の復帰先となる課題名・科目名を保存します。初期化時には旧処理用の `cg_grade_nav` を削除します。
- これらはUserscriptsの保存フォルダではなく、Safariの学情サイトのデータです。端末間の同期・引き継ぎは実装していません。Cookieをブロックした環境、ストレージへのアクセスが拒否される環境は未対応です。
- ファイルプレビューはSafariのPDF・画像対応とサイトのCSPに依存します。表示できない場合は元の添付リンクから開いてください。外部サイトの添付は通常のCORS制限を受けます。ログイン画面がHTTP 200で返る場合の自動判別は行いません。
- `page` への注入がCSPで拒否される場合は未対応です。`content` に変えるとページ側のjQueryや送信処理にアクセスできなくなるため、このスクリプトでは切り替えを解決策として案内しません（[Userscriptsの実行コンテキスト・CSPの説明](https://github.com/quoid/userscripts#metadata)）。

v1.12.1では，フッターの白い背景を透過しました．macOS Safariのログイン後のホームで，下端まで背景が続くことと，締め切り日時の一時保存を確認しています．v1.12.2では，学情のAJAX処理が課題一覧内の `#notSubmitReading` を取り除くまで，締め切りの再判定と一時保存の更新を待ちます．読み込み中の空一覧によって通常背景へ戻る問題を，警告・1日未満の両方で再現し，修正後の維持と読み込み完了後の再判定をテストしました．macOS Safariの学情ホームでも，修正前の「警告→課題なし→警告」を診断ログで再現し，修正後は初期表示から課題取得後まで警告背景を保つことを確認しました．初期背景の判定は，警告日数・1日未満への移行・期限切れ・ホーム以外・ストレージ拒否を自動テストで確認しました．新しいタブなど，一時保存がない場合は最新の課題一覧が出てから判定します．

v1.12.4では，課題・アンケートリストだけに半透明のスタイルを適用します．macOS Safariで，検索条件・詳細検索・結果一覧・表の見出しに背景が透け，提出済みの行は半透明の緑で区別できることを確認しました．検索条件や非表示操作の処理は変えていません．iOS・iPadOSの実機確認は未実施です．

### ローカル検証

Node.jsは [.mise.toml](../.mise.toml) に固定しています。外部npmパッケージは不要です。リポジトリ直下で実行します。

```sh
mise install
mise exec -- node --check src/Comfortable_Gakujo.user.js
mise exec -- node --test tests/*.test.cjs
git diff --check
```

検証時はNode.js v22.23.2で，計53件が通過し，構文チェックも通過しました．背景画像については3種類の保存・復元，n日と1日の境界，個別の解除，不正な日数，容量不足時の設定保持と設定画面の操作を確認しています．画像全体の縦横比を保った縮小，PNGからJPEGへの容量調整，容量超過・画像の読み込み失敗・保存失敗時のエラー表示と再選択，切り取り画面を挟まない保存もテストしています．待機なしの要素取得と背景CSSの先行追加，背景がメニューでぼかされる要素の外に置かれることも確認しています．ホームの半透明表示では，成績iframeの再読み込みへの追従，別オリジン・別画面のiframeを変更しないこと，学情側の通知欄の再描画後にスイッチとカウントダウンを一つずつ保つこともテストしています．macOS Safariでは，上部の情報を横並びにした配置，お知らせ・スケジュール・未提出課題・成績グラフ内の背景が透けることも確認しました．全体背景への変更後は，macOS Safariの学情ホームで通知とカウントダウンが潰れないこと，課題一覧で背景が表示され，課題一覧の表示と提出済みの色分けを確認しました．上部メニューと左バーの半透明表示（白いアイコン・文字を維持）と，Safariの表示幅を狭めた際にも背景の左上が(0, 0)で表示領域全体を覆うことを確認しました．iOS・iPadOSでの表示と，端末回転時の実機確認は未実施です．添付プレビューのテストでは，修正前にGETプレビュー1件・HTTPエラー2件の失敗を再現しています．

起動時間は，同じスクリプトを埋め込んだローカルHTMLで比較しました．画像の読み込みを2秒遅らせた条件で，変更前は約2590ms，変更後は約6msでヘッダー設定UIが追加されました．これはSafariでの一例で，Userscriptsの注入までの時間や実際の学情の通信時間を含む測定ではありません．

2026-10-21のmacOS Safariで，ホームの「課題提出」から一覧への遷移を計測しました．Navigation Timingでは，最初のPOSTからリダイレクト終了まで約2967ms，続くページの応答完了まで約450ms，DOMの準備完了まで約3500msでした．ページ側の `postSubmit` に固定の待機はなく，通常のフォーム送信を行っています．今回の主な待ち時間は最初のリダイレクトまでにあり，スクリプトの表の加工では短縮できません．計測は1回で，通信状況や学情の負荷によって変わります．課題の先読みや一覧のキャッシュは追加していません．

実機確認時は、各OSで登録・再読み込み・更新を行い、ホームのカウントダウンと通知、課題の非表示と復元、背景画像の保存・再読込・削除、成績フィルター、時間割順の選択、SSO、単位情報への遷移、添付のPDF・テキスト・画像表示を確認してください。提出取消の復帰は、実際に取消操作が必要な場合に確認してください。


## 対応環境と保存先

このスクリプトのAPI上の前提は **macOS 12以降かつSafari 15.4以降、またはiOS・iPadOS 15.4以降** です。Userscripts本体はApp Storeに表示される対応OSも確認してください。元コードの `crypto.randomUUID()` は [MDNの互換性データでSafari 15.4以降に対応](https://github.com/mdn/browser-compat-data/blob/main/api/Crypto.json) とされており、それ以前向けの代替実装は追加していません。これらの最低バージョンでの実機試験は未実施です。

iCloud Driveを保存先にする場合、同期が終わっていることを確認してください。対応OSではフォルダを「ダウンロード済みを保持」にすると、ファイルが端末から取り除かれるのを防げます。スクリプトの同期と、後述するCookie・ストレージの保存は別です。
