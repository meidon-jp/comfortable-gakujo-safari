# 更新履歴

### Safari Userscripts版 ver1.12.0

- 通常時・n日未満・1日未満の背景画像を，それぞれ選べるようにしました．
- 警告背景に切り替える日数を設定できるようにしました（初期値3日）．
- 以前の背景画像は通常時の設定として引き継ぎます．
- 横長のヘッダー画像枠をなくし，ウインドウ全体を背景にしました．上部メニューも半透明にし，画像はウインドウのサイズに自動で追従します．背景設定の鉛筆は右下に移しました．
- 背景画像の切り取り位置と拡大率を，保存前に調整できるようにしました．
- 起動時の読み込み完了待ちと固定500msの待機を外し，背景画像とレイアウトを先に反映するようにしました．
- 左側のバーを少し広げ，項目名が途中で改行されないようにしました．
- ホームのお知らせ・スケジュール・成績などを半透明にし，上部の名前・件数・締め切りを一つのパネルにまとめました．
- 学情側の再描画で成績通知スイッチが消える場合に，表示を戻すようにしました．

### 2026/10/21 Safari Userscripts版 ver1.11.4

- 元作者・MITライセンスを保持し、単体の `.user.js` にもライセンス全文を追加。
